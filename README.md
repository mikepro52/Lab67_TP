# АИС «Анализ продаж» — Меркурий

Учебный проект по варианту 12. Лабораторные 6.a, 6.b и 7: коллекция на классах JavaScript, вывод через DOM и сохранение в `localStorage`.

Магазин ведёт журнал продаж одежды, обуви, кожгалантереи и чулочно-носочных изделий. Покупателю после чека дороже 50 Br выдаётся дисконтная карта. Пока накоплено не больше 200 Br, скидка 3%. Дальше 5%, а после 500 Br — 10%. Скидка считается по сумме покупок до текущего чека.

## Как открыть

Файлы статические, сборка не нужна. Из папки проекта:

```bash
python3 -m http.server 8765
```

Затем откройте [http://127.0.0.1:8765](http://127.0.0.1:8765).

В шапке кнопка «Войти». Выберите сотрудника и отправьте форму. Без входа журнал только для просмотра: добавление, правка, удаление и поиск скрыты.

## Что есть на странице

- Журнал продаж: фильтры, сортировка и страницы по 10 чеков.
- Покупатели, товары, накладные и сотрудники.
- Отчёты руководителя: кто работал в выбранный день, клиенты со скидкой 10%, дни рождения и динамика товара по месяцам (поступление и продажа).

Правки не пропадают после перезагрузки. Чеки лежат в `localStorage` под ключом `ObjInf`, остальное состояние — под ключом `ObjInfState`. Если хранилище пустое, в него один раз записывается исходный журнал из `js/data.js`.

## Консоль

Те же действия доступны из консоли браузера. Команды собраны в `salesLab`.

```js
getObjs(0, 10)
getObjs(0, 10, { author: "Соколова Мария" })
addObj({ id: "101", description: "Пальто шерстяное, арт. PL-104, 1 шт.", createdAt: new Date(), author: "Соколова Мария", productName: "Пальто шерстяное", article: "PL-104", category: "Одежда", quantity: 1, unitPrice: 189, customerId: "c3", customerName: "Орлова Дарья Игоревна", customerPhone: "+375 29 445-10-77" })
setUser(null)
salesLab.reset()
```

`salesLab.reset()` возвращает исходные данные и выходит из учётной записи.

## Файлы

| Файл | Зачем |
| --- | --- |
| `index.html` | Пустая страница, данные в неё не вписаны |
| `js/data.js` | Исходные массивы, в том числе `ObjInf` |
| `js/model.js` | `ObjCollection` и `Shop`: проверка, фильтры, скидки, `save` и `restore` |
| `js/view.js` | Отрисовка через DOM |
| `js/main.js` | Контроллер: формы, делегирование событий, вход |
| `css/styles.css` | Оформление |
| `img/`, `assets/` | Картинки товаров |
